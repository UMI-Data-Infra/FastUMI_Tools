FastUMI Tools

FastUMI Team 官方签名 APT 软件源，支持 Ubuntu 20.04 Focal amd64。

配置并安装

curl -fsSLO https://km-data-pipeline.github.io/FastUMI_APT/install-fastumi-repository.sh
less install-fastumi-repository.sh
sudo sh install-fastumi-repository.sh --install

配置软件源后，可以随时安装或升级：

sudo apt update
sudo apt install fastumi-tools

启动与检查

安装后从应用菜单打开 FastUMI Tools。将相机连接到 USB 3.x 接口，然后在“SDK 和固件”页面确认相机序列号、连接速率以及设备实际报告的版本。

刷新固件时只连接一台相机，过程中不要拔线或断电。ROS 数据源与实时预览不能同时运行；预览可通过 Web 页面中的“关闭预览”停止。

升级与卸载

sudo apt update
sudo apt install fastumi-tools

sudo apt remove fastumi-tools fastumi-tools-resources

卸载本工具不会自动卸载单独安装的 XVSDK，也不会回退相机固件。
